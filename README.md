# Guess-the-thing-Game
Guess the thing is a web-based interactive guessing game. It is designed to provide users with engaging and intellectual gaming experience. Users can guess popular heroes, characters, movies, etc. It allows users to select category, difficulty levels , etc. Platform will gradually reveal so that hints so that user can guess the correct answer.  
It includes AI API INTEGRATION. All the hints are generated randomly by AI.
Problem Statement: Today, a large no of population of our country (INDIA) are increasingly consuming short form content, leading to continuous digital stimulation, dopamine hits, etc. This web application will help improve their cognitive and intellectual ability.
Technologies used:
HTML: It will provide basic structure to the website
CSS: It is used to design the appearance of the website (designs).
CSS FRAMEWORKS: Little bit of Bootstrap
JAVASCRIPT: It makes the frontend more interactive. All the messages, buttons and actions are performed by javascript.
Python: It is used in backend, mainly used for selecting and managing operations.
Flask: It connects the backend to the website, It receives requests from the server and perform certain actions.
SQL Lite: SQL lite is used as the database to store user's information such as no of guesses, streak, saved game data etc.
Git and Git hub: It is an online repository where users can interact and collaborate with their work (related to coding).
